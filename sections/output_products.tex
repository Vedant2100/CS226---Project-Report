\section{Output Products and Visualization}

The pipeline delivers four primary output products, all stored in S3 under a versioned \texttt{run\_id} prefix. First, a \textit{Raster Anomaly Map} renders each flagged pixel's Z-score as a spatially registered heatmap, enabling rapid visual identification of anomaly clusters that may correspond to disease foci or beetle infestation fronts. Second, an \texttt{anomaly\_events} Parquet file provides a tabular representation of all flagged pixel-months with their Z-scores, NDVI/NDMI values, and baseline statistics, suitable for downstream analytical workflows. Third, an NDVI heatmap timelapse GIF (RdYlGn colormap: green = healthy, red = stressed) provides an animated sequence of monthly NDVI composites for the selected evaluation window, enabling visual confirmation of canopy change over time. Fourth, a false-color NRG composite timelapse GIF (NIR $\rightarrow$ R, Red $\rightarrow$ G, SWIR1 $\rightarrow$ B; vegetation appears magenta) supports visual identification of vegetation loss episodes that correspond to Z-score anomaly clusters.

A Flask-based web dashboard is provided that accepts user-specified time ranges and spatial resolution (20\,m, 30\,m, or 50\,m) for Boulder County to invoke the anomaly detection pipeline on demand. The dashboard returns real-time anomaly detection results including monthly NDVI and NDMI trend charts, pixel-level scatter plots, Z-score distributions, top anomalous pixels, and an interactive geographic map. The timelapse GIFs are fetched directly from S3 and rendered in the dashboard immediately after pipeline execution, bridging the gap between statistical detection and ecological interpretation.
