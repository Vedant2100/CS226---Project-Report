\section{Conclusion}

This project proposes a scalable framework for detecting vegetation anomalies preceding plant disease outbreaks using large-scale satellite time-series data. Focusing on Boulder County, Colorado and the Mountain Pine Beetle (MPB) case study, the system integrates Harmonized Landsat--Sentinel-2 imagery, ESA WorldCover forest masking, cloud-native raster storage, and distributed PySpark processing to construct a spatiotemporal analysis pipeline. By combining efficient indexing, on-demand query execution, and Z-score–based anomaly detection, the architecture demonstrates how interpretable statistical methods can be deployed effectively within a Big Data environment.

Through structured evaluation of scalability, concurrency, query efficiency, and anomaly classification performance, the project validates both computational robustness and analytical rigor. Overall, this work demonstrates how scalable data engineering and ecological analysis can be combined to support large-scale forest health monitoring and future system expansion.
